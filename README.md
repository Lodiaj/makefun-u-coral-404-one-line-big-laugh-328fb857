## What it does

`main.ts` writes a single hilarious line — 200 characters or fewer, standing entirely on its own, with no title, setup, or explanation — to `/output/entry.txt`. The line is fixed and deterministic, so every run produces byte-identical output.

## The line

> My grandfather left me his watch in his will — generous of him, considering he's still alive and checks the time on my wrist every Sunday.

## Run

```sh
node main.ts
cat /output/entry.txt
```
